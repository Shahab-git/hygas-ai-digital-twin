HYGAS-AI Digital Twin - portable demo (University of Zagreb, NACHIP / DOK-ING MSW-H2 pilot)

START:   FIRST right-click the zip and choose "Extract All" (do not run it from inside the zip), then open the extracted folder and double-click run_demo.bat. The first start installs the packages (a few minutes; offline when the "wheels" folder is present).
STOP:    close the black window.

WHAT THIS IS
- A simulated digital twin of a 1 tonne/day waste-gasification hydrogen plant. Every number is a MODEL result. No plant measurement exists yet.
- This copy has no database and no keys. It cannot write anywhere and it does not connect to the published hourly runtime.
  The header says LOCAL DEMO for that reason.
- The 3D tab is a process-ordered schematic, not to scale (DOK-ING has given no CAD or layout).

DEMO TIPS
- Summary tab: press "Start live run" in the Live simulation section and move the feed slider.
- 3D Plant tab: click an item for its card; the buttons fit the view or focus on a group.
- Design Basis tab: what is confirmed, what is assumed, and what we are still asking DOK-ING.

REQUIREMENTS: Windows with Python 3.11 or newer (python.org). Nothing else.
